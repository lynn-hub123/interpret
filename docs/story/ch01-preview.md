# 第一章 · 十七层没有灯｜剧情预览

竖切片第一章，现代都市悬疑恐怖。H2（心理压迫，不见血）、R2（无亲密内容）、全性向（无默认性别代词）。
地点：城西临江写字楼 B 座。时间：十一月十七日，雨夜 23:40 — 00:10。
练习方向：全章 `zh2en`（提示中文，输出英文，角色说英文）。

三场是三个位置，人在真的走：大堂/楼梯间 → 电梯厅 → 回到 1704 门前。

---

## 第一场 · 楼梯间（场景界面，14 条）

雨夜，你替陈迟把箱子送到 B 座十七层。手里那张快递单湿了半边，**寄件人一栏是陈迟的字**——你来的原因从第一屏就在你手上。电梯停在 16，按也不动。

前台只开了半盏灯，周砚在值夜班。对方告诉你，这部电梯一个礼拜都只到十六层；看见快递单上的字，说上个月陈迟也来过，说要送东西上去，后来没下来。走楼梯可以，但楼梯拐角的镜子别往里看；上面要是陈迟叫你，别应。

周砚去按电梯，数字亮了一下又灭了。十六层到十七层之间，声控灯灭了两次；第二次你没跺脚，它也亮了。楼梯口很窄，再往里是一条长走廊。对讲机响了，周砚的声音里全是电流：上面要是墙上的电话响，别接。

**三次发言**：说明来意（送箱子 / 有人在等）、追问陈迟或请对方同行、答应不接电话。

---

## 第二场 · 电梯厅的公告栏（消息流，14 条）

十七层走廊很窄，尽头是电梯厅，灯管一闪一闪。电梯到了，门自己打开，周砚站在里面——对方只说，它想停十七层的时候就停。

公告栏钉着一叠值班表，边角一层层翘起来。**从 2003 到今年，每年 11 月 17 日都被红笔圈过；值班人一栏全是「周砚」，笔迹一模一样。只有今年的圈是新画的，墨还没干。**你问这些字是不是对方签的、是不是每年都在，对方答：二十二年，就在这层楼。

墙上的座机响了。听筒里问：「陈迟？是陈迟吗？」

**硬门禁 A**：你要对着听筒否认这个名字——「你打错了，这里没有这个人。」铃声停在半声上，走廊那头的门缝光没有动。周砚说，现在回那扇门去。你们往回走，经过消防门时，声控灯没有亮。

---

## 第三场 · 门内的声音（消息流，14 条）

走廊灯全灭，只剩 1704 门缝一条光。门内用陈迟的声音说「是我，开门」，并说出了只有你和陈迟知道的事：去年冬天你们在楼下等过一整夜出租车，以及**快递单背面那行字「别拆，等我上来」——那行字你没给任何人看过**。

周砚说那不是陈迟，每晚都这么说。办法只有一句：说不，说出口，嘴闭着，他进不来。随后把手横在门把前，指节发白。门把手自己转了半圈。

**硬门禁 B**：你要对门里的声音说不——「我不会给你开门。」门缝里的光收了一下，像有人退开一步。1704 的门自己开了，里面是空的，地上有一台老式录音机还在转，磁带快到头了。

周砚说电梯好了，你可以走了。你问对方要不要一起走，或是否还要留下。电梯门开着，停在这一层。你回头看，走廊尽头那盏灯下没有人；值班表最后一行多了一笔，墨还没干。

## 两个硬门禁

| | 门禁 A（第二场，电梯厅） | 门禁 B（第三场，门前） |
|---|---|---|
| 处境 | 座机点名问「是陈迟吗」，周砚站在电梯口 | 门内用陈迟的声音叫你开门，门把手在转 |
| 类别 | `speech_act` | `life_death` |
| 必需槽 | `who` + `polarity` | `who` + `action` + `polarity` |
| 参考译文 | You've got the wrong number — there's no one here by that name. | I'm not opening the door for you. |
| 沉默出口 | 听筒那头记住你的声音，第三场门内直接叫你 | 门自己开了，灯全灭；你活着下楼，周砚不再开口 |

A 练否定（「没有这个人」），B 练对象 + 动作 + 否定三件事说全。都不限时、不动分支。

## 陈迟怎么提前落下

1. 第一场开场：快递单的寄件人栏是他的字（你在替谁跑这一趟）。
2. 第一场中段：周砚认出字迹，说他上个月也来过，说要送东西上去，没下来。
3. 第一场后段：周砚的警告点名他——「上面要是陈迟叫你，别应」。
4. 第二场：座机里直接问「是陈迟吗」。
5. 第三场：门内说出快递单背面的字，那行字你从没给任何人看过。

## 信息槽的说法

| 槽 | 本章取法 | 出现处 |
|---|---|---|
| `who` | 具体对象或否定代称：`someone` / `Chen Chi` / `no one` / `you` | 送件、追问、两个门禁 |
| `action` | 动作短语：`take up` / `come up` / `sign` / `pick up` / `open the door` / `stay` | 每场 |
| `time` | 时长与时间点：`how long` / `every year` / `all along` | 第二场追问、第三场追问 |
| `polarity` | `negative`：`no one` / `won't` / `not` | 答应不接电话、两个门禁 |
| `quantity` | 数字或量级：`one box` / `a signature` | 第一场送件、第二场签收 |

判定对照的是提示面那句中文原意，不要求与参考译文逐字一致；语序、拼写、口音转写错误都不影响通过。
