# 内容尺度分级（O2 已拍板，v4，目标 16+）

状态：方案 v4（目标分级改为 16+；Steam 国际版为主，买断制）｜ 日期：2026-11-14
前置文档：`2026-11-12-chat-rpg-repositioning-design.md`（§2 新定位、§10 O2）

## 0. 一句话

推荐做法：**四轴分级（恐怖 H / 非人 N / 亲密 R / 图像 C）+ 章节级标注 + 运行时表现开关**，目标分级 **16+**。H3「强心理恐怖」与 R3「暧昧张力与性暗示」均恢复可用，但**一律不写性、不见血**；第一版以 H2 + R2 为常态，关键章/关键关系节点可到 H3 / R3。渠道以 **Steam 国际版为主，买断制，无广告无内购**（见 §11.1）。

---

## 1. 为什么需要这一层

- 作品以 **Steam 国际版**为主要发行渠道，同时保留 PWA 形态用于分享与测试；仍需要统一的内容标尺。
- **目标分级 16+**：H3 强心理恐怖与 R3 暧昧暗示可用；红线（写实血腥、性行为描写、自伤细节）仍不做。
- 恐怖 + 奇幻 + 全性向三条线叠在一起，容易在无意识中越过受众边界。
- 美术与音频成本受尺度直接影响：越露骨、越写实，返工与风险越高。
- 分级必须能在**内容层表达**，否则作者写作、美术出图、QA 验收都没有统一标尺。

## 2. 四个分级轴

### 2.1 恐怖强度 H0–H4

| 档 | 名称 | 表现手段 | 典型内容 | 备注 |
|---|---|---|---|---|
| H0 | 无恐怖 | 只有悬疑氛围 | 日常对话、轻微不安 | 可作为无障碍档 |
| H1 | 轻悬疑 | 暗示、错位、未知 | 门自己关上、消息延迟 | 不出现威胁实体 |
| H2 | 中恐怖（**常态档位**） | 中等强度的氛围恐怖：压迫感、非人存在、声音异常 | 井底喊名、影子不对、夜里的脚步 | 不写实描写伤害 |
| H3 | **强心理恐怖（16+ 启用）** | 持续压迫、精神崩坏、非人感、死亡暗示、不可靠叙述 | 认知错位、被困、名字被叫走、叙述者撒谎 | **不见血也能达到**；逐章标注 + 提示 + 开关 |
| H4 | 极端 | 写实血腥、猎奇、折磨与自伤细节 | —— | **任何版本都不做** |

原则：恐怖来自**信息缺失、不可控与心理压迫**，不来自血腥。H3 是「强心理恐怖」而非「强血腥恐怖」——持续压迫、精神崩坏、非人感、死亡暗示、不可靠叙述都能达到 H3；写实血腥、折磨细节、自伤细节即使在 H3 也一律禁止。

#### 2.1.1 H3 的启用条件（**16+ 下的质量控制条款**，不是封禁）

**H3 在 16+ 下已启用；以下条件用于保证强度可控、可降级、不越红线。**

1. **逐章标注**：该章 `rating.horror = "H3"`，并写明具体触发点；不允许整部作品默认 H3。
2. **前置提示**：章节入口展示强恐怖提示，列出 `horror:death` / `horror:body` 等标签。
3. **降级可用**：低恐怖模式必须能覆盖该章，降级后剧情信息完整、不出现无法理解的跳变。
4. **渠道口径**：按 Steam 国际版 16+ 与 IARC 问卷执行；若某地区映射高于 16+，该地区需评估或降级（见 §11.1）。
5. **不叠加硬门禁**：H3 章节内不设硬门禁，避免「恐怖 + 考试」双重压力。
6. **严守红线**：H3 仍不得出现写实血腥、身体破坏特写、猎奇式折磨、自伤细节。
7. **QA 复核**：按标签与开关跑一遍，确认降级路径可通。

未满足任一条，该章按 H2 落地。

### 2.2 非人角色呈现 N0–N3

| 档 | 形态 | 表现 | 共情难度 | 美术成本 |
|---|---|---|---|---|
| N0 | 纯人类 | 普通角色 | 低 | 低 |
| N1 | 人形 + 非人特征（推荐默认） | 影子、异色瞳、多余关节 | 低 | 中 |
| N2 | 半人形（推荐上限） | 人形轮廓 + 器物/兽形部件 | 中 | 中高 |
| N3 | 非人形 / 抽象 | 雾、群体、无固定形体 | 高 | 高（需专门设计语言） |

原则：非人 ≠ 猎奇；先保证「能对话、能共情」，再谈异形程度。N3 角色必须以文字与声音承担主要塑造。

### 2.3 关系与亲密表现 R0–R3

| 档 | 关系表现 | 文本 | 画面 | 备注 |
|---|---|---|---|---|
| R0 | 无关系线 | 友谊 / 敌对 | 无 | —— |
| R1 | 暧昧与试探 | 暗示、拉扯 | 无 | 第一版主线可覆盖 |
| R2 | 确认关系（**常态档位**） | 明确表白、承诺、拥抱 | 非露骨 | 全性向同一标准 |
| R3 | 暧昧张力与性暗示（**16+ 启用**） | 可写张力、暗示、未说出口的话，用意象承载 | 非露骨、不得性暗示构图 | 不写性行为；常规手法见 §2.3.1 |
| R4 | 极端 | —— | —— | 不做 |

原则：**全性向 = 所有关系线对任意玩家身份开放**，不因性别/取向改台词、改尺度、改结局质量。

#### 2.3.1 R3 写法规则（**16+ 下的常规手法**：可写张力与暗示，不写性）

**R3 在 16+ 下已启用。允许暧昧张力与性暗示，仍一律不写性行为；本节是主路径，不是备用方案。**

**可以写**

- 关系与情感：靠近、犹豫、确认、承诺、拒绝、离别、重逢。
- 暧昧张力与性暗示：目光、距离、语气、未说出口的话；用意象与留白承载，不落到动作与器官。
- 身体感受的「外围」：呼吸、温度、心跳、手指收紧、衣料摩擦声、沉默的长度。
- 环境意象替代：潮水涨落、灯芯将尽、门缝的光、雨声、缆绳收紧、海面下的暗流。
- 时间跳切：写到临界点即切场景（灯灭、门关、消息中断），事后用一句回指。
- 事后反应：次日称呼变了、门口多了一件外套、有人先走、有人留下。
- 明确写「发生了什么」，但**不写「怎样发生」**。

**一律不能写**

- 任何性行为动作、体位、器官、体液、插入/高潮等直接描写。
- 露骨呻吟、拟声词、羞辱性称呼、以性为卖点的调情。
- 露骨 CG、裸露性器官、明显性暗示构图；C3 不开放。
- 未成年角色的任何性化或暧昧化（绝对红线，任何档位不例外）。
- 强迫 / 非自愿的过程细节；可以写威胁与后果，不写过程。
- 用比喻、换词、留白包装的上述内容——**换词不算合规**，按原意判断。

**替代手法（按顺序优先）**

1. **意象替换**：用潮、灯、绳、雾、钟等世界内意象承担张力，不落到身体动作。
2. **感官侧写**：只写听觉、温度、触感等外围感受，不写解剖细节。
3. **时间跳切**：在临界点切走，下一场景再回指。
4. **留白与打断**：NPC 消息中断、场景切换、输入框被收起。
5. **角色台词代替叙述**：让角色说一句似是而非的话，叙述层不解释。

**示例**

- ✅「灯芯爆了一下。你听见自己的呼吸，比潮声还近。」
- ✅「第二天早上，她把你的外套叠好放在门口，什么都没说。」
- ✅「那晚之后，钟楼的门再没锁过。」
- ❌「他解开你的衣扣，手往下……」——动作直写。
- ❌ 任何器官、体液、拟声词。
- ❌「像潮水一样进入」——用比喻掩盖明确动作，仍按违规处理。

**R3 审查清单**

1. 是否出现性行为动作、器官、体液、拟声词。
2. 删掉所有比喻后，原意是否仍是性描写；是则删。
3. 是否可被截图为露骨画面（含构图暗示）。
4. 是否涉及未成年角色。
5. 是否含强迫过程细节。
6. 是否只写「前后」而不写「过程」。

命中任一条即退回重写。R3 需逐章 `rating.intimacy = "R3"` 标注；可在关键关系节点使用，不追求数量。

### 2.4 图像尺度 C0–C3

| 档 | 类型 | 内容 | 备注 |
|---|---|---|---|
| C0 | 无图 | 纯文字 + 头像 | 成本最低 |
| C1 | 场景插画（推荐默认） | 氛围图、场所、物件 | 不出现角色特写 |
| C2 | 角色 CG | 角色立绘、关键场面 | 非露骨；需统一画风 |
| C3 | 露骨 CG | 性/血腥特写 | **任何版本不做** |

## 3. 第一版推荐档位

| 轴 | 16+ 下第一版落地 | 说明 |
|---|---|---|
| 恐怖 | **H2 为常态，关键章可到 H3（强心理恐怖）** | 不见血；H3 按 §2.1.1 的质量控制条款执行 |
| 非人 | **N1–N2 混合** | 人形为主保证共情与成本，关键角色可用 N2 |
| 亲密 | **R2 为常态，关键节点可到 R3（暧昧暗示，不写性）** | 按 §2.3.1 主路径执行 |
| 图像 | **C1 为主，少量 C2（B5 已定）** | 先出一版看效果，不做 C3 |

组合含义：**中到强心理恐怖 + 人形/半人形 + 暧昧张力 + 非露骨插画**，整体对齐 16+。这与 11-12 §2.1「现代悬疑恐怖 + 奇幻」的定位一致。

## 4. 分级在内容层怎么表达

### 4.1 内容标签

每条可能触发边界的内容，打一个或多个标签：

- `horror:body` 身体异变
- `horror:death` 死亡威胁
- `horror:psychological` 精神压迫
- `nonhuman:uncanny` 非人违和感
- `relationship:intimacy` 亲密关系
- `audio:jump` 突发音效
- `visual:flash` 闪烁画面

标签用于**筛选、提示、开关**，不直接等于分级。

### 4.2 章节级分级与前置提示

```json
{
  "id": "ch03",
  "rating": { "horror": "H2", "nonhuman": "N2", "intimacy": "R1", "cg": "C1" },
  "warnings": ["horror:death", "audio:jump"],
  "note": "井底喊名；有一次突发音效"
}
```

- 进入章节前展示一次**内容提示**（可折叠、不打断）：恐怖强度、是否有突发音效/闪烁、是否含亲密内容。
- 不做强制确认弹窗；提示出现在章节标题下方或加载时的一行小字。
- 提示不剧透，只描述强度类别。

### 4.3 运行时开关

| 开关 | 作用 | 默认 |
|---|---|---|
| 低恐怖模式 | 把 H3+ 的表现降到 H2，删突发音效与闪烁，保留剧情 | 关 |
| 关闭突发音效 | 只去 `audio:jump` | 关 |
| 关闭闪烁 | 只去 `visual:flash` | 关 |
| 文字优先 | 用文字替代部分 CG / 音效演出 | 关 |

原则：**开关只降表现，不删剧情、不改结局**；低恐怖模式下故事信息必须完整。

### 4.4 与作者标注的关系

- `rating` 四轴字段**必填**（校验器强制），默认值由模板给出。
- `warnings` 按标签表选填，但 QA 会按标签反查。
- 章节实际内容不得超过其 `rating` 声明；超出视为内容错误。

## 5. 红线（任何档位都不做）

1. 明确的性行为描写、器官与体液描写、露骨 CG（C3 不开放；R3 只按 §2.3.1 的意象写法执行）。
2. 写实血腥、身体破坏特写、猎奇式折磨（H4 不开放；H3 也不得触碰）。
3. 对未成年角色的性化或暧昧化。
4. 真实宗教、民族、地域的贬损性刻画。
5. 自伤、自杀的细节教学式描写。
6. 以现实可识别的真实人物为原型的负面角色。
7. 任何要求玩家输入真实个人信息的剧情。

---

## 6. 全性向落实规则

1. 关系线不锁玩家性别、取向、身份；所有可攻略角色对所有玩家开放。
2. 角色台词不因玩家性别改写；涉及称谓时使用中性表达或角色专属称呼。
3. 亲密表现使用同一套尺度标准（16+ 下 R2 为常态、R3 可用但一律不写性），不因组合不同而加码或删减。
4. 结局数量与质量对等，不设「真结局只属于某一取向」。
5. 玩家身份可自定义时，文本避免默认性别代词；必要时用角色名或「你」。
6. 非二元与性别未定角色按 §6.1 处理。

### 6.1 非二元与性别未定（B7 已定：包含）

**英文侧**

- 角色性别未定或非二元：统一用单数 `they / them / their`，动词按复数一致（`they are`、`they were`、`they have`）。
- 不用 `he/she`、`s/he`、`(s)he` 交替；不用 `it` 指人。
- 玩家角色永远用 `you`；其他角色提到玩家时用 `they` 或角色名，不默认 `he/she`。
- 自定义代词（如 `ze/hir`）第一版不做；统一 `they` 已覆盖非二元表达，避免文本模板爆炸。
- 信息槽判定不要求性别代词；`who` 槽按姓名/身份匹配。

**中文侧**

- 叙述层对玩家统一用「你」，天然无性别。
- 第三方角色首次出现用姓名或身份（「井婆」「那个工匠」），后续优先用「对方」「那个人」「这个人」，或重复名字。
- 避免默认「他/她」，也不写「他（她）」「他/她」。
- 必须用第三人称代词时，统一用「TA」或角色名；不按角色外观猜性别。
- 称谓用角色专属叫法（「先生」「姑娘」按角色设定），不按玩家性别改。

**叙述层性别未定时**

- 角色卡可不填 `gender`，或填 `"unspecified"`；不得由立绘/声音反推性别。
- 关系线、门禁句、结局文本都不因性别改写。
- 中英互译时保持人称一致：中文无性别 → 英文用 `they`；英文 `they` → 中文用姓名/「对方」，不译成「他/她」。
- 音频：英文 `they` 正常发音；中文避免性别化称呼，TTS 文本中不出现「他/她」。

## 7. 非人角色呈现规则

1. 非人角色首先要有**可理解的动机与说话方式**，异形程度服务于叙事，不服务于猎奇。
2. N2 及以上角色必须有稳定的视觉识别特征（轮廓、颜色、声音），避免「换个滤镜就是另一个角色」。
3. 非人角色的亲密线同样遵守 R3 规则（R2 为常态、R3 不写性）、§2.3.1 写法规则与 §6 全性向规则。
4. 恐怖场景中的非人角色不做「虐待式」展示；威胁来自存在方式，不来自折磨细节。
5. N3 角色以文字与音频为主，CG 只做氛围，不做解剖式特写。

---

## 8. 与 O1 硬门禁的关系

- 内容强度影响门禁句的选择：**H3 场景不叠加硬门禁**，避免「恐怖 + 考试」双重压力；H2 场景可用，但已标 `horror:death` 时也应谨慎。
- 低恐怖模式下调低表现强度，但硬门禁判定不变；提示仍叙事化。
- 门禁句的 `failEffect` 不得使用红线内容（血腥、露骨）作为惩罚表现。
- 内容提示与门禁前置信号是两件事：前者在章节入口，后者在单句作答前。

---

## 9. 落地流程

1. 编剧按章节填写 `rating` 与 `warnings`，并对照红线自检。
2. 美术按 `cg` 档与标签出图；C2 以上需标注是否可被低恐怖模式替换。
3. QA 按标签跑检查：章节声明的档位是否被实际内容超出；开关是否能完整降级。
4. 每次新增章节，走同一张分级表，不临时口头约定。

## 10. 推荐方案总览（含已拍板结论）

| 维度 | 结论 | 说明 |
|---|---|---|
| 分级方式 | 四轴独立分级 | 避免一个总分掩盖具体风险 |
| 目标分级 | **16+** | 国内适龄提示 16+ / PEGI 16 / ESRB T–M / Steam IARC 按地区映射 |
| 恐怖 | **H2 常态，H3 可用（强心理恐怖）** | 不见血；H3 守 §2.1.1 与红线 |
| 非人 | N1–N2 混合 | 共情优先、成本可控 |
| 亲密 | **R2 常态，R3 可用（暗示不写性）** | 按 §2.3.1 主路径执行 |
| 图像 | **C1 为主，少量 C2** | 先出一版看效果；不做 C3 |
| 标注位置 | 章节级 `rating` + `warnings`，强制校验 | 可在内容层检查 |
| 玩家提示 | 章节入口一次 | 不打断、不剧透 |
| 降级方式 | 表现开关，不删剧情 | 保证故事完整 |
| 全性向 | 同尺度、同质量 + 非二元代词 | 规则见 §6.1 |
| 红线 | 七条，任何档位不做 | 见 §5 |

### 11.1 发行渠道、目标分级与发行模式（已定）

- **目标分级：16+。** 映射口径：国内适龄提示 16+、PEGI 16、ESRB T/M、Steam 走 IARC 问卷按地区映射；若某地区映射高于 16+，该地区按映射结果处理。
- **主要发行渠道：Steam 国际版。**
- **发行模式：买断制；不做广告，不做内购。**
- **TapTap 与国内商店暂不作为发行渠道**，仅作社区与测试用途；不为其单独做合规裁剪。
- H3（强心理恐怖）与 R3（暧昧暗示）在 16+ 下可用，但一律守 §2.1.1、§2.3.1 与 §5 红线。
- 年龄门：不做成人年龄门；Steam 按 16+ 填写内容问卷，页面展示内容提示。
- 若未来调整渠道或分级，再按本文档重新校准。

原 D1（发布渠道）与 D2（是否需要年龄门）已随 16+ 目标与 Steam 发行确定，不再待定。
