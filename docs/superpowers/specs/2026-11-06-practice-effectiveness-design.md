# 练习效果规格：目标与「掌握」判定

状态：**存档参考（2026-11-14 降级）**｜原状态：草稿（待确认，2026-11-06）
日期：2026-11-06｜复核：2026-11-14
范围：练习目标、掌握判定、练习循环。**不含**剧情扩展、美术、反馈 UI。

> **降级说明（2026-11-14）**
> 本文写于「三阶段练习卡」时期。新方向改为对话驱动后，**「过关」已由 O1 硬门禁承担**：玩家按下发送时按信息槽判定这句话发不发得出去；掌握与 SRS 归 O9。本文不再作为验收依据，整体降为存档参考，仅保留少数统计口径备查（见 §9），逐节处置见 §8。

## 0. 一句话

这是一个「用翻译推进剧情」的 RPG：剧情独立于翻译，玩家把**自己想说的话**译成英语来行动。练习目标是**视译产出**，不是把玩家培养成翻译员。

## 1. 目标能力

- **主目标：视译产出**（看完中文，限时说出英文）。
- 不单独立项：听辨理解、复述、词汇记忆——可作为辅助维度，但衡量指标只围绕视译产出。

## 2. 两层判定

| 层级 | 判定条件 | 作用 |
|---|---|---|
| **过关** | ① 独立复现 ② 正确性达标 ③ 限时说完 | 推进剧情、落进度、计券 |
| **掌握** | 过关 + SRS 间隔复测仍达标 | 标记「已掌握」，进羁绊/图鉴/统计，**不卡剧情** |

- 「过关」= 这次做到了；「掌握」= 过几天还记得。
- 剧情只被「过关」门控；「掌握」只影响沉淀与统计，不阻塞推进。

> 2026-11-14：上表的「过关」三条件已被 O1 取代——①独立复现改为「R3 之前不展示参考译文」；②正确性改为信息槽命中（AI 只升级不否决）；③限时说完默认不做。可保留的是「掌握不卡剧情」这一条。新文档请用「门禁通过」，不要再沿用「过关」。

## 3. 四项指标定义

1. **独立复现**：在未显示参考译文的状态下完成产出（三阶段第①段）。
   - 判定：产出（录音/提交）发生在 reveal 之前。
2. **正确性**：AI 判分 / 参考译法对比达到阈值——信息完整、无明显错误（不要求字面一致）。
   - 判定：AI 评分达阈值，或「自评能译 且 AI 非 miss」。
3. **流利度**：单句限时内说完。**先只做「限时」，不做停顿/卡顿检测。**
   - 判定：产出耗时 ≤ 该句限时（按长度/难度设定，如 8–15 秒）。
4. **保持率**：该句在 SRS 到期复测（如 +3 天、+7 天）仍满足「过关」。
   - 判定：复测过关 → 写入「已掌握」集。

## 4. 练习循环（一屏一件事）

三阶段不变：① 产出 → ② 对照译文 → ③ 评分。

- **阶段①**：未看译文，限时产出 → 决定「独立复现」「流利度」。
- **阶段②**：显示参考译文，对照。
- **阶段③**：评分（AI + 自评）→ 决定「正确性」。
- 三项齐 → 该句「过关」；过关句进入 SRS 队列；到期复测达标 → 转「掌握」。

## 5. 现状与差距

| 指标 | 现状 | 差距 |
|---|---|---|
| 独立复现 | 已有（三阶段先产出后对照） | 无 |
| 正确性 | 有 AI 判分（`grade.js`） | 缺「达标阈值」定义 |
| 流利度 | 有计时器（`settings.showTimer`） | 缺「单句限时 + 超时判定」 |
| 保持率 | 有间隔复习（`srs.js`） | 缺「复测达标 → 转掌握」回写 |
| 掌握集合 / 进度联动 | 无 | 需新增 |

## 6. 非目标（本轮不做）

- 卡顿 / 语气 / 发音的自动检测
- 听辨、复述的独立评分体系
- 剧情与素材扩展（另开一轮）
- 云同步、账号

## 7. 建议默认值（待确认）

1. **正确性达标**：AI 分档 ≥ 75（原始分 ≥ 62.5）。AI 不可用时退回自评——自评「能译」= 达标，「磕绊 / 不会」= 不达标。
2. **单句限时**：按参考译文长度估算——英文约 2.5 词/秒、中文约 4 字/秒，+2 秒缓冲，下限 6 秒；超时不算过关（本轮不做停顿检测）。
3. **保持率 / 掌握**：沿用现有 SRS 阶梯 `INTERVALS = [1,3,7,14,30,60]`；该句 `box ≥ 3`（已扛过一次 7 天间隔复测）记为「掌握」，`box 1–2` 视为「过关 / 巩固中」。

## 9. 可复用概念（备查）

以下口径在后续设计里还能用，但**都不作为门禁条件**：

1. **独立复现**：定义为「未看参考译文时的产出」。对应 O1 中 R3 之前的状态，可作统计项；是否通过由信息槽决定，不由是否独立复现决定。
2. **保持率 / 掌握集**：复测达标才转「掌握」，掌握不卡剧情。归 O9，作为 SRS 与统计的设计输入。
3. **流利度作为统计口径**：记录单句耗时与是否「说完」，只进统计与限时节点校准，不做判定。O4 §8 的 20 秒 / 30–45 秒可用这套口径标定。
4. **「掌握不阻塞推进」原则**：与新 O1「门禁结果不影响分支能否选」一致，可直接沿用。
5. **§6 非目标清单**：仍是有效的排除项，可作为 O9 / O10 的边界说明。

术语提醒：新文档统一用「门禁通过 / 未到位」，不要再用「过关」，避免与旧的「过关 = 三条件齐」混淆。
