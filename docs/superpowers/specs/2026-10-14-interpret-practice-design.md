# Interpret（口译随手练）设计文档

- 日期：2026-10-14
- 状态：已与用户逐节确认
- 工作名：Interpret（口译随手练）

## 1. 背景与目标

口译训练的常见障碍是"开始成本高"：每次练习都要先找材料、搭环境，导致练不起来、手感流失。

本产品秉承**随时开练**原则：打开页面即可抽句口头翻译，两次点击完成一轮（看参考 → 自评），零打字、零准备、零心理负担，让用户随时随地"来一句"，保持翻译敏感度。

**成功标准**

- 从打开页面到译出第一句 ≤ 3 秒（无注册、无配置、无加载等待）
- 一轮练习全程只需 2 次点击（看参考、自评）
- 手机端单手可完成全部操作（PWA 安装后像原生应用）

## 2. 关键决策记录

| 决策点 | 结论 | 理由 |
|---|---|---|
| 目标用户 | 第一版按个人工具做，架构留开放余地 | 先解决自己的问题，不为假设需求过度设计 |
| 练习形式 | 视译优先；音频交传为后续版本 | 视译零依赖、打开即练，最贴合"随时来一句" |
| 句子来源 | 内置题库 + 随手粘贴 | 题库是"无材料开练"的根基；粘贴满足针对性练习 |
| 反馈方式 | 对照参考译文 + 三档自评（能译/磕绊/不会），本地记录 | 无外部依赖；自评即记录，积累复习数据 |
| 交互 | 纯口头零打字；中英双向可切换 | 口译本体是口头；打字打断节奏 |
| 实现路径 | PWA（纯前端静态站 + 可安装离线） | A 方案全部优点 + "随时随地"完整体验，成本低 |
| 练习页布局 | A 卡片翻转式呈现 + C 会话历史入口 | 单句聚焦 + 可回看，取两者之长 |
| 复习机制 | 零压力：弱句混入抽句 + 可选弱项回顾列表 | SM-2 式"待复习 N 句"会变成待办债，违背无负担初衷 |

## 3. 整体架构

**技术栈**

- Vite + Vue 3 单页应用
- `vite-plugin-pwa` 提供可安装与离线缓存（manifest + service worker）
- Vitest 做单元测试
- 纯静态产物：可部署到任意静态托管，本地 `dist` 也可直接使用

**数据与存储**

- 内置题库为静态 JSON，随构建打包
- 所有用户数据存 localStorage，统一封装为独立 storage 模块，暴露稳定接口（存取记录、导入导出、损坏兜底）——第一版不涉及后端，未来开放加账号时只需替换该模块实现，上层不动
- 提供 JSON 导出/导入，兜底换设备与备份场景

## 4. 页面结构

底部 Tab 导航（保持单任务聚焦，移动优先）：

1. **练习**（首页）：核心抽卡练习流，含会话历史入口
2. **题库**：按主题浏览（经济 / 外交 / 科技 / 日常……），点主题进入连续练习
3. **粘贴**：粘贴任意文本 → 自动拆句 → 立即开练
4. **复习**：近期"磕绊/不会"句子回顾列表（可选入口，非任务清单）
5. **我的**：统计（连续天数、今日/累计句数、主题强弱）、导出/导入、设置（默认方向等）

## 5. 核心练习流（抽卡翻转式）

```
显示原文卡（含 中→英 / 英→中 切换、跳过）
   ↓ 口头翻译
点「看参考」→ 卡片翻转显示参考译文
   ↓ 对照
点自评：能译 / 磕绊 / 不会
   ↓ 自动
下一句
```

- 全程两次点击，零打字；自评动作本身即完成记录
- 会话历史入口：从练习页顶部进入，按对话流样式回看本轮练过的句对（原文 + 参考译文 + 自评）
- 可选计时显示（设置项，默认关）

## 6. 数据模型

- **句子**：`{ id, zh, en, topic, source: 'builtin' | 'custom' }`
- **练习记录**：`{ sentenceId, direction: 'zh2en' | 'en2zh', rating: 'ok' | 'shaky' | 'miss', ts }`，只增不删
- **设置**：默认方向、是否显示计时、亮/暗主题等

## 7. 零压力复习机制

- **无队列、无任务数、无提醒**：不出现"待复习 N 句"这类义务性信息
- **弱句混入抽句**：抽句时约 30% 概率从"近期弱句"中抽取，其余随机（同主题或全库，跟随入口）；同句不连续重复出现。"近期弱句"定义：最近 7 天内被评过"磕绊"或"不会"的句子
- **弱项回顾**（复习页）：最近 30 天"磕绊/不会"句子列表，按时间倒序，纯回顾工具——想看就点进去重练，不看也完全不欠
- 统计页所有数字均为"已发生的事"，不渲染任何"欠着的事"

## 8. 视觉风格

- 默认深色 + 拟物柔和（neumorphic）质感，支持亮/暗切换
- 强调色为绿色系（"开口说话"的活力感）
- 移动优先布局；核心练习页一屏只有一张卡，视觉焦点唯一

## 9. 错误处理

- localStorage 不可用（如隐私模式）或已满：练习照常进行，仅提示"本轮不保存记录"
- 存储数据损坏：解析失败时先备份原始数据为副本，再重置该项，不静默丢数据
- 导入 JSON：先校验格式，不合法即拒绝并提示，绝不覆盖现有数据
- 粘贴为空 / 拆不出句子：明确提示，不进入练习流
- PWA 新版本：提示刷新，不打断当前练习

## 10. 测试策略

- **单元测试（Vitest）**
  - storage 模块：存取、导出/导入、损坏兜底、配额满处理
  - 拆句逻辑：中英文标点、缩写、多段落
  - 抽句算法：弱句混入比例、去重、方向过滤
  - 统计计算：连续天数、主题强弱分布
- **手动验收清单**：抽卡流全链路（原文 → 口译 → 翻转 → 自评 → 下一句）、历史回看、粘贴开练、导出导入、离线打开 dist
- **构建验证**：`npm run build` 通过；dist 在本地打开且离线可用

## 11. 范围外（后续版本）

- 音频交传模式（TTS/音频播放 + 影子跟读）
- AI 点评接口（留扩展位，需用户自有 key）
- 多用户/账号系统（storage 模块已抽象，替换实现即可）
- 更多语言对

## 12. 题库内容规划（第一版）

- 主题：日常、经济、外交、科技、环保、教育、体育、文化（8 类）
- 每类 20–30 句，中英对照，单句长度以一次口译 10–30 秒为宜
- 题库为纯静态 JSON，后续可持续追加而不改代码
