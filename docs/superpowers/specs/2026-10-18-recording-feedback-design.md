# 录音反馈优化（计时器 + 脉冲动画）设计规格

日期：2026-10-18
状态：已批准（用户确认方案 A 克制版：计时器 + 脉冲动画，逐节确认设计后批准）

## 背景与目标

练习卡录音区（PracticeCard.vue + recorder.js）当前反馈极简：点击「🎙 录音」后按钮变红色「⏹ 停止」，停止后出现原生 `<audio controls>` 回放条，失败时显示具体错误文案。录音过程中除按钮变色外没有任何其他状态指示，用户「不知道是不是真的在录」。

本次聚焦**录音中状态**：加计时器和呼吸脉冲动画。回放美化和录后引导为后续独立迭代，不在本次范围。

## 需求澄清结论

| 决策点 | 结论 |
|--------|------|
| 反馈程度 | 方案 A 克制版：计时器 + 按钮脉冲动画，不加波形可视化 |
| 范围 | 仅「录音中状态」；回放体验、录后引导留待下一轮 |
| 动画实现 | 纯 CSS，不上 JS 驱动 |

## 1. 计时器

- 录音成功启动后，录音按钮旁显示 `00:00` 格式计时（mm:ss），每秒递增
- 视图层实现：PracticeCard.vue 内 `setInterval` 每秒更新；recorder.js 不动（计时属 UI 状态，非调度逻辑）
- 清理时机：停止录音、切换句子（现有 sentence watch）、组件卸载
- 录音失败不启动计时
- 停止录音后计时器隐藏，回放条照旧出现（现状不变），不保留最终时长显示

## 2. 脉冲动画

- 录音中的「⏹ 停止」按钮（`.btn-rec.recording`）加呼吸脉冲：CSS `box-shadow` 缓慢扩散回缩，低饱和红（与现有错误红 `#e8463a` 同族但降饱和），iOS 风格缓动（ease-in-out）
- 尊重系统设置：`@media (prefers-reduced-motion: reduce)` 下关闭动画
- 仅 CSS keyframes，不改按钮结构

## 3. 测试策略（TDD）

- PracticeCard.test.js 补用例（vi.useFakeTimers）：
  - 录音启动后显示计时器且随时间递增（00:00 → 00:01 → 00:02）
  - 停止录音后计时器消失
  - 切换句子时计时清理（重挂录音后从 00:00 重新计）
- 现有录音区 5 个用例保持全绿

## 4. 改动边界

只动两个文件：

- `src/components/PracticeCard.vue`：模板加计时显示、脚本加 interval 逻辑与清理、样式加脉冲动画
- `src/components/PracticeCard.test.js`：新增用例

不动：`src/lib/recorder.js`、PracticeView、其他页面、回放条样式。

## 5. YAGNI 边界（本次不做）

- 实时音量波形/圆环可视化
- 最长录音时长限制与提示
- 回放区美化、自定义回放控件
- 录后引导动作闭环
- 保留最终时长显示
