# 像素点缀 UI 改造 · 设计交接

状态：**三步已全部实施**（2026-11-04）
日期：2026-11-04
范围：视觉语言、主线画面层级、练习页交互层级

## 一、要解决的问题

三套视觉语言并存，互相打架：

1. 全局 neumorphism（`.neu-raised` / `.neu-inset`，双向软阴影、16px 圆角）—— 现代 iOS 质感
2. `LingSprite.vue` 的 16×16 像素铃 —— 硬边、有限色
3. emoji 当 UI 图标（🌊 🎴 🎙 🔊 🎧）—— 与铃气质冲突最明显

另有两个结构性问题：

- **场景没有画面**。`scn02_tidehead.json` / `scn03_wreckbeach.json` 的 `place / time / premise` 在 `PracticeView.vue` 里只渲染成一行文字，RPG 的「到场感」为零。
- **一屏五个可点区**。练习页同屏有：模式切换、方向切换、录音、抽卡、历史。第一眼不知道手该放哪。

## 二、已定决策（用户逐条确认）

### 决策 1：像素点缀（非全像素、非换皮）

保留现有软底和布局，只把「壳」像素化：

- 卡牌 / 按钮 / 对话框换成 **直角 2px 描边 + 单向硬投影**
- emoji 图标全换成 **8×8 方格图标**
- 铃保持不变，它就是这套图标的基准

理由：改动集中、风险低，能立刻把气质拉回一个世界。全像素化要重写全部样式且中文字体与可读性代价大；只加插画则风格分裂仍在。

### 决策 2：每场一张场景图

- 16:9 像素风插图，贴在场景条顶部，高约 120–140px
- 压暗至约 40% 亮度，**下缘渐隐到 `--bg`**（不是硬切圆角），像从黑暗里透出来
- 图上叠文字：左侧竖排章节号 + 地名，底部一行 `时间 · 精灵`
- 右上角一枚小齿轮 → 打开「本场设置」（模式、方向、计时）
- **图缺失时兜底为 CSS 潮线**（一条随时间下降的水平线 + 刻度），不允许出现破图
- 自由练习页不加载任何场景图

理由：点进去第一眼看到画面而不是文字，是补「到场感」最直接的方式。

### 决策 3：一屏只做一件事（渐进披露）

练习卡分三阶段，主区域一次只承载一个动作。

| 区域 | ① 提问（未作答） | ② 对照（已录音） | ③ 评分（已看译文） |
|---|---|---|---|
| 卡片主区 | 角色 + 原句 + 方向 | 原句 / 译文上下分层 | 四档评分 |
| 录音 | 大按钮，居中 | 收成「重录」小字 | 隐藏 |
| 评分 | 不出现 | 不出现 | 展开 |
| 顶部条 | 本场 3/16 · 券 ×2 · 齿轮 | 同 | 同 |
| 铃 | 一句引导 | 沉默 | 一句即时反应 |

**关键行为变更**：现在「录音完就能评分」，等于没看答案就打钩。改成 录音 → 看译文 → 自评，评分必须晚于对照。

## 三、视觉硬规则（实施时必须遵守）

1. **单向光源**：所有硬边控件只用「右下 4px 实心块」投影，不用双向软阴影。软阴影只留给非控件容器（背景板、抽屉、浮层）。
2. **画布对齐**：像素元素按 4px 网格落地——边框 2px、缺口 12px、图标 8×8 放大到 16 或 24，避免半像素模糊。
3. **颜色只做强调**：像素描边只有两种——中性 `--border` 与金色（羁绊 / 稀有）。绿色只用于按钮与进度，不当装饰。
4. **角上缺口**：卡片左上角开 12px 方口露出底层色，是像素卡的身份标记（软 UI 做不出这个）。

## 四、图标清单（8×8，两色）
