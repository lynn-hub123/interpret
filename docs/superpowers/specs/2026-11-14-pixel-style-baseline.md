## 0. 一句话

**只把「壳」像素化，不把整页像素化。** 像素语言负责边框、投影、图标、动效与图片渲染；正文排版仍以可读性优先。铃（`LingSprite.vue`）是这套视觉的基准物，所有新元素向它对齐。

---

## 1. 适用范围

**适用**

- 聊天气泡、输入区、录音/识别控件、发送按钮
- 门禁态（前置信号、缺槽提示、R3 对照区）
- 设置抽屉、章节入口、结算页、图鉴 / CG 外框、限时提示条

**不适用**

- 剧本正文与长段落排版（按可读性走，不套像素框）
- 商店页、外部登录页、平台原生弹窗
- 角色插画与 CG 的画面内容本身（那是美术规范，不是 UI 规范）

---

## 2. 硬规则

以下每条都是可验收的，不是风格建议。

### P1 · 4px 网格

- 间距、尺寸、位移一律取 4 的倍数：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 描边 2px 是网格下的最小视觉单位，仅用于描边，不用于间距。
- 图标按 8×8 设计，只放到 16 / 24 / 32 的整数倍；禁止 20、28 这类非整数倍缩放。
- 禁止 `top: 13px`、`width: 37%` 之外的半像素定位；不用 `transform: scale(1.15)` 缩放像素元素。

### P2 · 单向光源

- 所有硬边控件只有**右下 4px 实心**投影：`box-shadow: 4px 4px 0 var(--px-shadow-color)`。
- 控件**不用**双向软阴影（neumorphism）；软阴影只允许出现在非控件容器：背景板、抽屉、浮层、场景图遮罩。
- 按下态：`transform: translate(4px, 4px)` 且投影归零，形成「压进去」的位移，不用缩放。

### P3 · 直角与双色描边

- 控件 `border-radius: 0`；唯一例外是场景图本身（图片内容不受限）。
- 描边只有两种颜色：中性 `--border` 与金色 `--gold-text`（羁绊 / 稀有 / 关键物）。
- 绿色 `--accent` 只用于主操作按钮与进度，不做装饰描边、不做标题色。

### P4 · 角上 12px 缺口

卡片左上角开 12×12 的缺口，露出底层 `--bg`，缺口右侧与下侧各 2px 描边。这是像素卡的身份标记，软 UI 做不出来。

```css
.px-card::before {
  content: '';
  position: absolute;
  top: -2px; left: -2px;
  width: 12px; height: 12px;
  background: var(--bg);
  border-right: 2px solid var(--border);
  border-bottom: 2px solid var(--border);
  pointer-events: none;
}
```

### P5 · 原生字号阶

只允许五档，不新增中间值：

| 档 | 字号 | 用途 |
|---|---|---|
| XS | 12px | 元信息、时间戳、状态提示、按钮副标 |
| S | 20px | 正文、NPC 与玩家消息、输入框 |
| M | 24px | 角色名、小节标题、结算项名 |
| L | 36px | 场景标题、章节号 |
| XL | 48px | 结算大数字、章节标题、无图占位标题 |

- 行高 1.5–1.6；中文正文不小于 20px，12px 只用于不承载信息的短标签。
- 现有壳里残留的 14px / 15px 属于遗留，**新增界面不得再引入非阶值**。

### P6 · 阶跃动效

- 过渡一律 `steps()`，不用连续缓动：按下 `80ms steps(2, end)`，面板展开 `160ms steps(4, end)`，消息入场 `120ms steps(3, end)`。
- 转场用**位移推**，不用淡入淡出：水平推 24px 后归位，避免长距离 opacity 渐变。
- 闪烁、脉冲等重复动画同样分档；必须响应 `prefers-reduced-motion: reduce`，命中时全部关闭。

### P7 · 8×8 双色图标

- 图标 8×8 网格、最多两色：中性（`--text-muted` / `--border`）加一个强调色（`--accent` 或 `--gold-text`）。
- 位图图标放大时 `image-rendering: pixelated`；SVG 图标按 8×8 整数格绘制，不用亚像素曲线。
- **禁止用 emoji 当 UI 图标**（🌊 🎴 🎙 🔊 🎧 这类）。emoji 只可出现在台词内容里，且不作为控件标识。
- 铃的 16×16 是基准，新图标与它同笔画重量、同色数。

### P8 · 50% 棋盘抖动

- 半透明盖层、遮罩渐隐、阴影过渡一律用 50% 双色交错，不用平滑渐变：

```css
.dither {
  background-image: repeating-conic-gradient(
    var(--dither-a) 0 25%,
    var(--dither-b) 0 50%
  );
  background-size: 4px 4px;
}
```

- 抖动只用于**装饰与过渡**，不铺在正文背后；文字区域必须保证对比度，抖动层与文字之间加实底。
- 场景图下缘遮罩用阶梯或抖动过渡，不用跨半屏的平滑渐隐。

### P9 · 图片与资源

- 场景插画与 CG 都按像素风出图，放大显示时 `image-rendering: pixelated`。
- 场景图整体压暗至约 40% 亮度，下缘过渡到 `--bg`。
- 资源放 `public/` 下按类型分目录；只加载当前场景/当前章的图，不做全量预载。
- **图缺失时必须有兜底**（CSS 潮线、纯色块 + 标题），不允许出现破图或空白块。

### P10 · 色彩纪律

- 强调色最多三个：绿（主操作 / 进度）、金（羁绊 / 稀有）、中性描边。
- 恐怖场景靠压暗与降低饱和度制造压迫，不靠加红、加紫、加高饱和。
- 深色为默认主题，浅色主题只换变量值，不改结构。

## 3. 禁止事项

1. 全像素换皮：把正文、长段落、设置项全部塞进像素框。
2. 用像素字体排正文（中文字形缺失、可读性差）；像素字体只用于标题与数字。
3. 控件使用圆角、双向软阴影、玻璃拟态、渐变按钮。
4. 非 4px 网格的尺寸与位移；非整数倍图标缩放。
5. emoji 作为 UI 图标或状态标识。
6. 大面积平滑渐变遮罩（改用抖动或阶梯）。
7. 为「好看」增加第四种强调色。
8. 动效使用连续缓动、弹性回弹、超过 200ms 的进场动画。
9. 图片缺失时留破图、留白块或临时占位图上线。
