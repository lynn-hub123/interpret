# 真人感语音（预生成音频 + 自然音色兜底）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 内置题库 320 句预生成为微软自然语音 MP3 随应用分发，实时 TTS 升级为自动优选在线自然语音兜底，播放统一收口到新封装 voice.js。

**Architecture:** 生成脚本（node + msedge-tts）离线产出 `public/audio/{id}.{zh|en}.mp3` 提交入仓；运行时 voice.js 按句子来源选路（builtin → 播音频文件，失败回退 TTS；custom → 直接 TTS）；workbox 对 audio/*.mp3 用 CacheFirst 运行时缓存。

**Tech Stack:** Vite + Vue 3 + Vitest(happy-dom)、msedge-tts@2.1.0、vite-plugin-pwa workbox。

**规格：** `docs/superpowers/specs/2026-10-18-voice-design.md`

**环境备忘（Windows PowerShell 5）：**
- npm/npx 用 `.cmd` 后缀（`npm.cmd test`），多命令用 `;` 不用 `&&`
- 提交信息用中文单行（无空格免引号），如 `git commit -m 音频生成脚本与预生成语音资产`
- 本机代理 `http://127.0.0.1:7897`，若脚本连不上微软端点：`$env:HTTPS_PROXY='http://127.0.0.1:7897'` 后重跑（脚本已内置对该环境变量的支持）

- [ ] **Step 1.3: 写生成脚本 `scripts/generate-audio.mjs`**

```js
// 用微软 Edge 自然语音为题库预生成朗读音频（仅本地运行，产物提交入仓）。
// 用法：node scripts/generate-audio.mjs [--force]
//   默认跳过已存在的文件；--force 全量重新生成。
// 本机网络需代理时设置 HTTPS_PROXY 环境变量即可，脚本自动使用。
import { readdirSync, readFileSync, existsSync, mkdirSync, writeFileSync } from 'node:fs'
import { join, dirname } from 'node:path'
import { fileURLToPath } from 'node:url'
import { MsEdgeTTS, OUTPUT_FORMAT } from 'msedge-tts'

const root = join(dirname(fileURLToPath(import.meta.url)), '..')
const outDir = join(root, 'public', 'audio')
const libraryDir = join(root, 'src', 'data', 'library')
const force = process.argv.includes('--force')

// 声音按规格固定：中文晓晓、英文 Andrew，默认语速
const VOICES = { zh: 'zh-CN-XiaoxiaoNeural', en: 'en-US-AndrewNeural' }

const proxyUrl = process.env.HTTPS_PROXY || process.env.https_proxy
let agent = null
if (proxyUrl) {
  const { HttpsProxyAgent } = await import('https-proxy-agent')
  agent = new HttpsProxyAgent(proxyUrl)
}

// 合成走 SSML 模板，输入含 &/</> 时必须转义
const esc = s => s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;')

let generated = 0
let skipped = 0
try {
  mkdirSync(outDir, { recursive: true })
  const files = readdirSync(libraryDir).filter(f => f.endsWith('.json'))
  for (const lang of ['zh', 'en']) {
    const items = []
    for (const f of files) {
      const arr = JSON.parse(readFileSync(join(libraryDir, f), 'utf8'))
      for (const s of arr) {
        const text = (s[lang] || '').trim()
        if (text) items.push({ id: s.id, text })
      }
    }
    // 每种语言一条连接，批量合成减少握手次数
    const tts = agent ? new MsEdgeTTS(agent) : new MsEdgeTTS()
    await tts.setMetadata(VOICES[lang], OUTPUT_FORMAT.AUDIO_24KHZ_48KBITRATE_MONO_MP3)
    for (const { id, text } of items) {
      const out = join(outDir, `${id}.${lang}.mp3`)
      if (!force && existsSync(out)) { skipped++; continue }
      const { audioStream } = await tts.toStream(esc(text))
      const chunks = []
      for await (const chunk of audioStream) chunks.push(chunk)
      writeFileSync(out, Buffer.concat(chunks))
      generated++
      console.log(`✓ ${id}.${lang}.mp3`)
    }
  }
  console.log(`完成：生成 ${generated}，跳过 ${skipped}（已存在）`)
} catch (e) {
  console.error(`生成失败（已生成文件保留，重跑续传）：${e?.message || e}`)
  process.exit(1)
}
```

```js
// TTS 封装：按语言朗读，同一时刻只播一句（播新先停旧）。
// 依赖全局 speechSynthesis / SpeechSynthesisUtterance，测试中用 vi.stubGlobal 注入 mock。
export function ttsSupported() {
  return typeof window !== 'undefined' && 'speechSynthesis' in window
}

// 优选在线自然语音：Edge 的 Natural 语音最自然，其次 Chrome 的 Google 在线语音，
// 都没有时回退第一个本地语音。
export function voicesFor(lang) {
  if (!ttsSupported()) return null
  const prefix = lang === 'zh' ? 'zh' : 'en'
  const list = window.speechSynthesis
    .getVoices()
    .filter(v => (v.lang || '').toLowerCase().startsWith(prefix))
  if (!list.length) return null
  return list.find(v => /natural/i.test(v.name)) || list.find(v => /google/i.test(v.name)) || list[0]
}

export function speak(text, lang, onend) {
  if (!ttsSupported()) return false
  const synth = window.speechSynthesis
  cancel()
  const v = voicesFor(lang)
  // 语音列表非空但缺该语言语音包 → 失败；列表为空（Chrome 首次异步加载）→ 交给引擎默认语音
  if (synth.getVoices().length && !v) return false
  const u = new window.SpeechSynthesisUtterance(text)
  u.lang = lang === 'zh' ? 'zh-CN' : 'en-US'
  if (v) u.voice = v
  if (onend) u.onend = onend
  synth.speak(u)
  return true
}

export function cancel() {
  if (ttsSupported()) window.speechSynthesis.cancel()
}
```

- [ ] **Step 3.3: 实现 `src/lib/voice.js`**

```js
// 统一播放入口：内置句优先播预生成音频，缺失/失败回退实时 TTS；自定义句直接 TTS。
// 单例语义与 tts.js 一致：同一时刻只播一个，播新停旧。
import { speak, cancel } from './tts.js'

let current = null // { audio, settle } —— 当前活动播放

function detachAudio(a) {
  if (!a) return
  a.onended = null
  a.onerror = null
  a.pause()
}

// 停止当前播放（幂等）：清理音频、停 TTS、并让等待方收到 'stopped'
export function stop() {
  const c = current
  current = null
  detachAudio(c?.audio)
  cancel()
  if (c) c.settle('stopped')
}

// Promise<'played' | 'stopped' | 'failed'>：正常播完 / 被新播放或 stop() 打断 / 兜底 TTS 也不可用
export function playText({ id, source, text, lang }) {
  stop() // 播新停旧
  return new Promise(resolve => {
    let state = null
    const settle = r => {
      if (!state || state.done) return
      state.done = true
      if (current === state) current = null
      detachAudio(state.audio)
      resolve(r)
    }
    state = { audio: null, done: false, settle }
    current = state // custom 句 TTS 播放期间也要可被 stop()
    // TTS 播放：custom 句直接走此路径；builtin 句音频失败后也落到这里
    const speakFallback = () => {
      const ok = speak(text, lang, () => settle('played'))
      if (!ok) settle('failed')
    }
    if (source !== 'builtin') { speakFallback(); return }
    const audio = new Audio(`${import.meta.env.BASE_URL}audio/${id}.${lang}.mp3`)
    state.audio = audio
    audio.onended = () => settle('played')
    audio.onerror = () => speakFallback()
    audio.play().catch(() => {}) // 播放失败最终会走 onerror，这里只防未处理拒绝
  })
}
```

script setup 改动：

```js
import { computed, onUnmounted, ref, watch } from 'vue'
import { playText, stop } from '../lib/voice.js'
import { ttsSupported } from '../lib/tts.js'
import { recorderSupported, startRecording, stopRecording, revoke, lastErrorName } from '../lib/recorder.js'
```

删除原 `onSpeak`/`onListenPlay`/`onUnmounted` 三个函数整体，替换为下方版本；`const ttsOK` 声明行保留原有位置不变（勿重复声明），其余按下面合并：

```js
const ttsOK = ttsSupported() // 运行期不变，无需响应式
// 内置句有预生成音频，无 TTS 引擎也能播；自定义句只能靠 TTS
const canPlay = computed(() => props.sentence.source === 'builtin' || ttsOK)
const playing = ref(false)

watch(() => props.sentence, () => {
  revealed.value = false
  listenTextShown.value = false
  listenError.value = ''
  speakError.value = ''
  stop()
  playing.value = false
  isRec.value = false
  if (recUrl.value) { revoke(recUrl.value); recUrl.value = '' }
})

async function playCurrent() {
  const r = await playText({ id: props.sentence.id, source: props.sentence.source, text: sourceText.value, lang: sourceLang.value })
  playing.value = false
  return r !== 'failed'
}

function onSpeak() {
  speakError.value = ''
  if (playing.value) { stop(); return } // 播放中再点 = 停止
  playing.value = true
  playCurrent().then(ok => {
    if (!ok) speakError.value = `设备缺少${sourceLang.value === 'zh' ? '中文' : '英文'}语音包`
  })
}

function onListenPlay() {
  listenError.value = ''
  if (playing.value) { stop(); return }
  playing.value = true
  playCurrent().then(ok => {
    if (!ok) {
      listenError.value = '当前设备无语音引擎，已显示原文'
      listenTextShown.value = true
    }
  })
}
```

`onUnmounted` 改为：

```js
onUnmounted(() => {
  stop()
  if (recUrl.value) revoke(recUrl.value)
})
```

注意：原 `onSpeak/onListenPlay` 里直接调 `speak(...)` 的同步判断逻辑（返回 false 立即提示）整体删除；原 watch/mode watch 里对 `listenError/speakError` 的清理逻辑保持不变。
